# Frozen construction-prefix dictionary pages, 2026-10-01

The native dictionary model is unchanged. Every canonical `Entry` packet,
including complete source bytes, Unicode spelling, duplicate occurrences,
linguistic structure and evidence, reconstructs exactly. The representation
splits reflected required root byte fields into a hot stream and preserves the
remaining nested packet byte adjacency in a cold stream. Cold bytes may use
exact quoted-field and ancestor register constructors before the same backend.

The fixed global policy was frozen on development data before this evaluation:
actually encode all three literal/local/local-plus-ancestor candidates, pay every
trial, choose the smallest complete frame, and break ties by lower opcode.
Constructor bounds and literal fallback were unchanged. No outcome below was
used to fit or alter the policy.

The untouched FINAL evaluation covers all 58,717 records in five source splits,
using the frozen parent generator's 1,248 identical native root groups. Both
backends pay complete ordinal envelopes, checksums, schema/routing headers,
restart directories, root offsets and constructor operands. Lexical and identity
indexes are equally outside this page representation comparison.

This is a repeatable size win on both OMW workloads. The three other workloads
grow; the result does not establish a universal compression improvement. All
OMW pages choose local-plus-ancestor constructors under both backends. The
development rich128 result remains +4.22% bzip3, and the older optional-label
field-spine alternative remains +19.5%; both negatives are retained.

Headword-only reads physically omit the cold stream. Necessary decoded stream
volume falls by 33.27× for Japanese, 13.71× for Mandarin, 15.71× for GCIDE,
16.96× for Spanish–English and 18.18× for English–French. These ratios are volume
facts. No latency clocks have run yet. Labels and definitions decode the cold
stream and pay its constructor inverse and a selected root packet copy.

The established natural projection loader keeps each exact original source
record in one `Inline.text`. This experiment does not add an XML-to-native
lexical importer. Rich native model tests cover varied morphology, nested
inlines, duplicate occurrences, opaque invalid-UTF8/NUL source bytes and exact
composed/decomposed spellings. Production dictionary APIs and core files were
not edited.

All selected pages and all three constructor modes pass native full semantic
admission and exact original canonical packet/frame checks: 234,868 native
entry admissions across the selected and candidate passes. Every complete
selected bzip3 and zstd bundle reconstructs the original frames. All identities,
headwords and direct projections agree; the native reflected frame agrees with
the encoder's frame. Both backends pay 3,744 construction trials and 3,744 hot
backend encodes. Native compressed access uses the existing bounded bzip3
backend; zstd is an independent complete-frame size control. Eight native Zig
tests and eighteen independent arbitrary-byte inverse cases pass; the shared
constructor additionally passed 464 independent Python/C++ differential cases.

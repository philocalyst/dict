# Global exact construction stock: corrected DEV evidence

The fixed ten-candidate LTCv2 family improves complete size against flat
packet-v3 compressed in the original source groups. It loses against actual
whole-flat compression. This is a dictionary representation result with a
resident shared stock, not a whole-file bzip3 victory or a cold-query speed win.

All numbers include actual headers, hashes, transmitted probability models,
literal/copy programs, root streams/offsets, and the original group directory.
Both backend controls are actual encoded, decoded, byte-checked artifacts.

The typed choices are `global_causal_owner_frequency` for rich128 and
`global_causal_joint` for OMW. They improve size by 22.24% / 17.73% and
23.63% / 25.61% against the original-page bzip3 / zstd19 controls. They cost
125.38% / 99.24% and 57.33% / 32.97% more than the whole-flat controls.
The complete-size winner is `global_causal_surface` in both cases; it carries
exact native packets and has no typed headword-prefix capability. These are
separate fixed access profiles; all ten candidate encodes are paid for either.
